# S Annapoorani - Portfolio Website

Personal portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Push to GitHub
```
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/Annapoorani1208/portfolio.git
git push -u origin main
```
(Create an empty repo named `portfolio` on GitHub first.)

## Deploy (GitHub Pages)
Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / root > Save.
Live URL: https://annapoorani1208.github.io/portfolio/
